What I work on

Agents, MCP servers and LLM features connected to the systems you already run: your store, help desk, email platform and APIs. Read-only by default, with every write behind its own switch.

How the work gets done

  • Measure first. Good projects usually start as a measurement, not a build. Sometimes the measurement shows the obvious build is the wrong one.
  • Checked against the real system. Production is the source of truth, not the docs or the dashboard.
  • AI-assisted, human-accountable. Code generation is a tool, like a compiler. Review, testing and responsibility stay with a person.
  • Yours to keep. Code, domain and accounts in your name, so you’re never locked in.
